# Regression PDF set

Place representative PDFs in the category folders. Do not rely on a single sample file.

| Folder | Intended coverage |
|--------|-------------------|
| small | Small text PDF |
| large | Large multi-page PDF |
| text-heavy | Dense text |
| image-heavy | Many images |
| scanned | Image-only / scanned pages |
| encrypted | Password-protected PDF |
| forms | AcroForm / filled fields |
| annotations | Annotation-heavy PDF |
| malformed | Corrupt or invalid PDF |

Files will be added when M2 engine tests need them. Do not commit copyrighted documents.
